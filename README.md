# LIT One-Page Spring Boot Clone

A polished one-page community website inspired by the supplied LIT Figma reference.

## Stack
- Spring Boot 3.5.16
- Java 17
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Cormorant Garamond + Manrope

## Brand colors
- #F4A101 — Gold
- #721022 — Burgundy
- #01224D — Navy

## Run
1. Open the project in VS Code / IntelliJ.
2. Make sure Java 17+ and Maven are installed.
3. Run:
   `mvn spring-boot:run`
4. Open:
   `http://localhost:8080`

The website is served from `src/main/resources/static/index.html`.

## Images
The demo uses remote Unsplash images for the London/community/event photography. Replace the URLs in `style.css` with client-approved images before production.
